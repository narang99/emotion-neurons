# Modes of the layer-25 neurons behind the MLP's emotion write

Per (emotion, pole): pos = pushes the kept dims along the write, neg = against it. Each mode is an HDBSCAN
cluster of the neuron's p97+ hits (share = hits in it, incl. assigned noise), named by Haiku from 5 exemplars.

Share of clustered modes named as the neuron's own emotion (controls: as any emotion): selected 14/420
